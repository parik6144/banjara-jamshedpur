# Banjara, Sonari --- Royal Restaurant Website

## Next.js + Cursor Build Specification

Build a **premium, royal Indian restaurant website for Banjara, Sonari**
using **Next.js**.

This is a redesign direction based on the actual Banjara logo and the
supplied restaurant photographs. The website must feel like the physical
restaurant: **Rajasthani-inspired, warm, colourful, handcrafted, elegant
and premium**.

Do NOT turn it into a generic black-and-gold luxury website.

------------------------------------------------------------------------

# 1. CORE DESIGN DIRECTION

## Brand Personality

Banjara should feel:

-   Royal
-   Indian
-   Warm
-   Welcoming
-   Authentic
-   Colourful
-   Premium
-   Family-friendly
-   Rajasthani-inspired
-   Experience-driven

The website should visually communicate the actual restaurant ambience
visible in the supplied photographs:

-   Warm golden lighting
-   Patterned upholstery
-   Rajasthani/Indian decorative artwork
-   Brass/gold tableware
-   Chandeliers
-   Arched architectural details
-   Maroon accents
-   Turquoise/teal decorative accents
-   Terracotta/pink interior tones
-   Rich wooden furniture

## IMPORTANT

Do NOT use an excessive "luxury jewellery" aesthetic.

Avoid:

-   Black + gold everywhere
-   Excessive metallic gradients
-   Chrome
-   Glitter
-   Fake 3D gold objects
-   Excessive glassmorphism
-   Huge glowing borders
-   Random luxury stock imagery
-   Generic palace imagery
-   Overly dark restaurant UI

The supplied restaurant photographs must be the primary visual identity.
